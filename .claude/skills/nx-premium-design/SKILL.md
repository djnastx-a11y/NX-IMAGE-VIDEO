# NX Premium Design

Use this skill to produce visually clear and credible work, not a generic AI-looking mockup.

## Workflow
1. Identify the exact output: image, storyboard, video, UI, export or critique. Record format, target platform and supplied assets.
2. Inspect the source material and existing approved visuals before suggesting a redesign. Do not replace an already approved layout.
3. Build one visual hierarchy: primary message, date/offer, secondary detail, brand signature. Preserve clear spacing, alignment and readable text.
4. For user-supplied portraits, logos and products, preserve the actual source. Do not silently substitute a synthetic likeness, generic logo or invented product.
5. Use restrained typography, balanced contrast, clean margins and platform-safe areas. Avoid unnecessary 3D labels, glowing outlines, decorative frames, purple/gold clichés and fake premium effects.
6. If a request is for an existing visual edit, change only approved regions and inspect the entire resulting frame for unintended alterations.
7. Deliver in the exact requested ratio and file format. Check 9:16 safe areas for stories, 16:9 for screens, 1:1 for posts when selected.
8. Review at native resolution, then at phone size: legibility, hierarchy, spelling, visual balance, faces, logo fidelity, missing text and crop.

## Australia Street conditional brand constraints
Apply these only to an Australia Street asset, not to unrelated NX, NASTX or client work.
- Use only the supplied official Australia Street logo, unchanged, never a redrawn lookalike.
- Do not add orange outside that official logo. Do not add kangaroos.
- Use the approved koala only when the specific production calls for it and source assets are available.
- Address when needed: 17 place Jules Ferry, Lorient.
- Never invent event dates, artists, promotions or availability. Never add an unwanted "entrée gratuite" statement.
- Prefer the already approved composition and change only requested content.

## Exit gate
Mark PASS only when every supplied source is respected, text is correct, the output is readable, ratio matches, and no unapproved assets appeared. When assets are missing, mark BLOCKED with the exact asset required rather than pretending the final is faithful.

## Examples for evaluation
- Refine a DJ NASTX poster but preserve a user-supplied real portrait and the approved layout.
- Create a 9:16 Australia Street teaser from supplied approved logo and bar photo without extra orange.
- Critique an overdecorated 90s/2000s visual and propose a balanced premium layout before editing.
